DOCTORCONNECT SIMPLE PATIENT PROJECT

Backend: PHP + JavaScript

Server: XAMPP

PAGES:
1. login.php
2. search_doctor.php
3. my_appointments.php

OTHER FILES:

book_appointment.php

SETUP:
1. Copy this folder to:
   C:\xampp\htdocs\

2. Start Apache and MySQL in XAMPP.

3. Open:
   http://localhost/phpmyadmin

4. Import:
   doctorconnect.sql

5. Open:
   http://localhost/DoctorConnect_Simple_Patient/login.php
